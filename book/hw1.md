# HW1

This covers Imitation learning and behavior cloning. This is equivalent to the supervised learning mode of LLMs. This is prior to doing RL fine tuning. We aren't using LLMs here but small robots which we can simulate on colab CPU mode. There are different versions of the Mujoco robot ranging from Mujoco to Mujoco-mpc to Mujoco XLA. Each version is far more sophisticated than the previous version and adds additional topics for discussion.
